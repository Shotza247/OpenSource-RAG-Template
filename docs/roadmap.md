# Roadmap

1. Establish the clean repository, configuration map and local chunk preview.
2. Add the HF token privately; confirm a free hosting path and compatible embedding contract.
3. Curate the public corpus and run the first real embedding import.
4. Test retrieval before generation; then connect one tool-capable hosted model.
5. Evaluate answers, citations and unknown facts; integrate the existing portfolio chat.
6. Add Google Drive for selected documents with scoped credentials, revisions and deletion handling.
7. Add optional Redis/Valkey caching after measurement; Prometheus for metrics and Loki for logs.
8. Add deployment/restore checks, access controls and a public hosting decision before claiming production readiness.

No paid service is authorized. Open-source code, model licenses and hosted-service prices
are separate decisions. Google Drive is the agreed proprietary document-source exception.
Shared inference free tiers have limits; a dedicated hosted endpoint is not assumed free.
Do not replace the user's hosted-model preference with local models without discussing it.
